Redesign the existing portfolio website without rebuilding the entire visual language from scratch.

https://www.aura.build/templates/tale-52-17

Place FEIZEN around the tunnel:

- Right side.
- Upper area.
- Lower area.

# 20. PERFORMANCE

This is critical.

The current About section has noticeable frame drops.

Investigate the actual cause before adding more animation.

Check:

- GSAP animations.
- ScrollTrigger.
- Lenis.
- React re-renders.
- requestAnimationFrame loops.
- IntersectionObservers.
- Event listeners.
- CSS filters.
- backdrop-filter.
- blur effects.
- excessive box-shadow.
- excessive DOM nodes.
- continuously animated elements.

Use animation primarily through:

```css
transform
opacity
```

Avoid animating:

```css
top
left
width
height
margin
padding
```

unless necessary.

Pause animations outside the viewport.

Clean up GSAP contexts and event listeners.

Use IntersectionObserver for sections that only need entrance animation.

The Hero should have the most visual movement, but it must remain lightweight.

The About section should prioritize smooth scrolling over decorative animation.
